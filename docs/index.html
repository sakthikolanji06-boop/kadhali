Kadhali

A multilingual voice AI assistant that runs on your own machine with your own NVIDIA key. Tamil, Hindi, English, code help, and optional phone → PC control.

Download APK Source on GitHub

Run it

git clone https://github.com/sakthikolanji06-boop/kadhali.git
cd kadhali
./run.sh --lan
  • Open the printed URL, paste your NVIDIA key once
  • Install kadhali.apk on your phone and enter the same URL
  • Add --control for the opt-in PC panel (token + audit log)
MIT licensed. Your key never leaves your computer.
