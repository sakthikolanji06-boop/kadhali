Capabilities

Built like a product,
runs like your own tool.

Everything happens on your hardware. The phone is a remote and a microphone; your machine does the thinking.

Live voice, 40+ languages

Speech in, speech out with a female voice that follows the language you picked. Hands-free mode keeps listening after every answer.

Code you can actually run

Fenced code blocks get copy and Run buttons, so Python, JS and shell snippets execute right in the chat instead of being decoration.

Streaming, no waiting

Tokens stream over SSE with smart model routing, so short questions answer instantly and long ones keep typing as they think.

Your own PC, under your thumb

Screenshot, volume and media, lock, typing, window list, files and an allowlisted command runner — token-gated and audited.

Private by architecture

The NVIDIA key is read on the server only. The browser and phone never see it; history stays in local storage.

Real APK, no store

The UI is bundled inside a signed 75 KB APK. Install it directly, launch instantly, and point it at your server once.

Phone → PC

Control your own computer,
not somebody else's.

Start the server with --control and pair once. Every action is written to an audit log, files stay inside your home folder, and power commands need an explicit confirmation.

  • Screenshot & windows — see the desktop, list and focus windows
  • Volume, media, lock — practical actions, no hidden extras
  • Type & keys — send text, Enter, Backspace, shortcuts
  • Allowlisted commands — a fixed list, never arbitrary shell

Get started

Three steps, no accounts.

Python 3.9+ and an NVIDIA NIM key. That is the whole dependency list for the server.

Run the server

Clone the repo and start it on your LAN. It prints the URL your phone needs.

$ git clone …/kadhali
$ cd kadhali
$ ./run.sh --lan

Add your key

Paste your NVIDIA key once in settings, or keep it in key.txt. It never leaves the server.

# or
$ echo nvapi-… > key.txt
$ chmod 600 key.txt

Install the APK

Grab the release, install it, enter the printed URL. Add --control for the PC panel.

$ adb install -r kadhali.apk
# then: ./run.sh --lan --control

Bring your own key.
Keep your own data.

Kadhali is free, open source and runs entirely on hardware you control.
